The console remains API-backed and uses `credentials: include`; no client
tenant ID is serialized. Accessibility fixtures are synthetic only. Forbidden
states are explicit and deny by default without disclosing tenant, account,
amount, or raw server error fields. This task performs no write, audit event,
provider call, real credential use, or financial-data processing.

Correct forward only: if independent QA or hosted CI finds a defect, preserve
this candidate and add a fresh isolated Frontend remediation branch plus a new
QA review. Do not weaken the capability gate, amend history, reset, force-push,

certification, contrast-engine result, hosted runtime evidence, or proof of the
full TASK-0119 authenticated deployed customer console. Those remain required
before any production-capability claim.
