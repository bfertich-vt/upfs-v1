# TASK-0007 handoff

## Scope

Added a dependency-free customer-console transaction search workbench backed exclusively by the versioned projection search API. The page supports tenant scope supplied by the authenticated API session, bounded cursor pagination, loading/empty/error/forbidden/retry states, projection consistency metadata, and evidence references.

## Security and accessibility

The browser client never sends a tenant identifier or uses a privileged endpoint. API authorization remains server-side. Results are rendered with `textContent`, not HTML interpolation. Form controls and result tables have accessible labels, live status updates, keyboard-operable buttons, and disabled loading controls.

## Tests and evidence

`apps/customer-console/transaction-search-workbench.test.mjs` covers endpoint/request contract, absence of tenant shortcut, forbidden handling, and retryable server failures. Browser-facing behavior uses the same exported module and requires no framework runtime.

## Operational notes

The projection is eventually consistent and PostgreSQL remains authoritative. The page displays the projection watermark/consistency marker and evidence references; it does not mutate financial state. Rollback is a file-level revert and API reads remain available.

## Non-goals

No privileged admin views, exports, writes, client-side authorization, or production credentials are included.
