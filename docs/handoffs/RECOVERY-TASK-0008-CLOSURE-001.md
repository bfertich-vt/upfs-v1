- The request has a closed shape and contains no tenant or environment identifier. A verified actor is mapped to an opaque UUID tenant/environment scope by an injected server-side identity boundary, then an independent deny-default policy decision is required before retrieval.

- Model output is closed, accessor-free, bounded cited-claim data. Missing, duplicate, foreign, mismatched, extra-fact, or malformed citations deterministically refuse.
- Async retrieval/model calls have bounded timeouts. A newer scoped request supersedes an older result; cancellation and replay conflicts fail closed. Identical scoped replay returns the original verified answer/citations with a fresh request identifier and separately recorded metadata-only audit event.

Events contain hashes, stable outcome metadata, and counts only; they exclude prompts, records, answers, descriptions, account/transaction/evidence IDs, amounts, currency, tenant/environment IDs, and provider/customer payloads.
