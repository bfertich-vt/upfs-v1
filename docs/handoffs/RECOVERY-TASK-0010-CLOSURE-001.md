- Authentication and `admin:read` are deny-default. Actor claims must be closed primitive records with bounded scopes, tenant assignments, environment assignments, session identifier, and step-up state. - Foreign and absent tenant/environment requests use the same `404 resource_not_found` envelope. Tenant listing filters by verified assignments, so it cannot enumerate other tenants.
- Support input is only an opaque reference. The injected broker result must match the exact reference, actor, tenant, allowed environments, independent approver, step-up state, case, bounded reason code, and future RFC3339 expiry. Raw reason text is neither accepted nor emitted.

- Responses are constructed from closed allowlists and carry `tenant_metadata` or `operational_metadata` classification. Tests exclude account, transaction, evidence, credential, secret, routing, provider, and customer-financial payloads.
- The audit sink receives a frozen metadata-only event before release. Audit failure releases no protected response and persists no local audit copy. Denials, invalid requests, dependency outage/timeout, cancellation, and success are correlated and audited without sensitive values.
- Malformed or stale health and malformed/partial projection snapshots return bounded dependency errors. Pre/post shaping cancellation returns no data. Constructor snapshots prevent concurrent fixture mutation from widening results.
