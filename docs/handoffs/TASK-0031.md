# TASK-0031 — External-readiness integration contract

Implemented a versioned, policy-checked contract and fail-closed evaluator for managed PostgreSQL, secrets/signing, observability, backup targets, cells/regions, and protected environments. The default report is `NO-GO_EXTERNAL_PREREQUISITES`; the evaluator never provisions services, reads credentials, deploys, or accepts non-synthetic evidence.

Evidence: `node --test scripts/task-0031-external-readiness.test.mjs`; run `node scripts/task-0031-external-readiness.mjs` to produce `artifacts/task-0031-external-readiness-report.json`.
