# TASK-0014 handoff

- Scope: reproducible migration, security, recovery, and environment-sized load rehearsals.
- Implementation: `scripts/task-0014-rehearsal.mjs` runs ordered migration/RLS and contract checks, additive expand/contract compatibility checks, synthetic BOLA/secret scans, checkpoint/outbox recovery checks, and a bounded 25,000-operation load gate. When `UPFS_DATABASE_URL`, `UPFS_RESTORE_DATABASE_URL`, `psql`, `pg_dump`, and `pg_restore` are present it applies migrations, creates a custom-format backup, restores into the separate disposable target, and executes an RLS-scoped query. Missing prerequisites are explicitly `skipped`; command failures are `failed` and never pass.
- Evidence: `scripts/task-0014-rehearsal.test.mjs` includes backup/restore ordering, tenant query escaping/isolation, and load-threshold failure injection; report artifact `artifacts/task-0014-rehearsal-report.json`; synthetic-only fixtures. Run `node scripts/task-0014-rehearsal.mjs` and `node --test scripts/task-0014-rehearsal.test.mjs`.
- Security and tenant isolation: checks forced RLS/policies in every migration and denies a synthetic cross-tenant lookup. No credentials or customer data are used; PostgreSQL probe output is not persisted.
- Recovery and rollback: migrations are applied one at a time with single-transaction mode in a disposable database. Failed migrations stop immediately. Production rollback remains corrective-forward per migration policy; no deployment or external database mutation is performed without an explicitly supplied disposable URL.
- Current external evidence: this environment has no `UPFS_DATABASE_URL`, Docker, or PostgreSQL client prerequisite, so live PostgreSQL migration, backup/restore, RLS, and load evidence is not claimed. The report is fail-closed and marks the live prerequisite skipped.
- Optional local evidence: pinned dev dependency `embedded-postgres@18.4.0-beta.17` and `npm run rehearsal:postgres:embedded` start two isolated temporary clusters, apply every migration, and verify FORCE RLS with a non-superuser role. In this environment that rehearsal passed migration and tenant-isolation checks; the package does not ship `pg_dump`/`pg_restore`, so backup/restore remains explicitly skipped and still requires external client binaries. The opt-in test (`UPFS_RUN_EMBEDDED_POSTGRES=1 node --test scripts/task-0014-embedded-postgres.test.mjs`) is never part of the fast default suite.
- Known follow-up: run the same command against an isolated disposable PostgreSQL instance before pilot authorization; retain the generated report with release evidence.
