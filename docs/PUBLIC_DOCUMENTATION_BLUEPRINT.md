# Public documentation blueprint

Use a versioned docs-as-code site generated from OpenAPI, AsyncAPI, JSON Schema, registries, and curated conceptual guides. Provide quickstarts, sandbox credentials, copyable validated examples, SDK parity, authentication/permissions, errors, rate limits, webhooks, pagination, idempotency, canonical objects, search, skills, workflows, policies, security, changelogs, migration guides, status/support, and production checklists.

Every example runs in CI against a mock or ephemeral sandbox. Search indexes each version independently. Deprecations show replacement, dates, impact, and migration. Sensitive internal topology, detection rules, customer details, and control evidence remain in access-controlled internal docs.
