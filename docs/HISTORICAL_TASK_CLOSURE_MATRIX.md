## Disposition rules

**complete** requires current implementation satisfying every surviving criterion plus fresh independent acceptance. **superseded** requires an accepted current capability covering every surviving criterion. **retired** requires an explicit owner decision removing the requirement. **blocked** is used here because required implementation or independently verifiable evidence is not established. Synthetic, reference, contract-only, absent, or unsupported evidence is never promoted to production capability.

## Review gate

An independent QA/Security agent must review the exact committed R2 state from an isolated worktree before integration or historical status changes.
