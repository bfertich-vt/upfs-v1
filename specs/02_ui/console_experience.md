# Customer console experience

The console uses an Elastic-inspired dense navigation and inspection model while remaining original and accessible. Every object, state, metric, relationship, and execution is drillable; every mutation displays scope, impact, required permission, audit effect, and rollback behavior.

## Navigation

Overview; Platform; Data; Search; AI; Workflows; Governance; Developers; Operations.

## Page contract

Every page specification must define purpose, personas, permissions, data classification, KPIs, widgets, tables, filters, actions, bulk limits, states, API mappings, events, audit, performance budgets, accessibility, documentation, acceptance tests, and non-goals.

## Priority pages

Dashboard, Organizations, Environments, Connectors, Sync Jobs, Ingestion, Quarantine, Canonical Objects, Entity Resolution, Relationships, Knowledge Graph, Evidence, Search Workbench, Indexes, Schema Registry, Data Quality, Models, Prompt Studio, Skills, Tool Registry, Context Builder, Chat Playground, Memory, Evaluations, Workflows, Executions, Approvals, Policies, Audit, Regulatory Corpus, API Explorer, SDKs, Webhooks, Documentation, Monitoring, Releases, Incidents.
