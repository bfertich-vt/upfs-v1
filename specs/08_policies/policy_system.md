# Policy system

Policies cover RBAC/ABAC, tenant isolation, data access/redaction, consent, AI use, prompt/tool restrictions, approvals, retention, exports, residency, support access, and release promotion. Evaluation is independent of the model and fails closed.

Decisions include allow/deny, policy/version, reason codes, obligations, evaluated attributes, and correlation ID. Publishing requires tests, impact analysis, approval, versioning, shadow evaluation, measured rollout, and rollback.
