# Personas and journeys

- Bank developer: connects data, uses SDKs, embeds search/chat, debugs requests.
- Bank administrator: configures environments, policies, users, retention, and approvals.
- Analyst: explores canonical records, relationships, evidence, search quality, and data quality.
- AI engineer: versions skills, prompts, context profiles, evaluations, and model routes.
- UPFS operator: monitors fleets and performs governed remediation without default access to financial data.
- Auditor: receives time-bound read-only access to selected controls and evidence.

Core journey: create sandbox → connect sample source → inspect raw observation → review normalization/evidence → build search profile → test cited answer → configure policy → embed component → observe usage and audit trail → promote a signed release.
