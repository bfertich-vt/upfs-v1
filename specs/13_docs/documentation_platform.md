# Documentation platform

Publish versioned public and internal documentation from contracts and registries. Public information architecture: quickstarts, concepts, canonical schema, connectors, search, AI skills, workflows, policies, governance, API reference, SDKs, webhooks/events, security, production readiness, examples, changelog, migrations, troubleshooting.

CI blocks undocumented endpoints, schemas, events, permissions, errors, configuration, broken links, invalid examples, stale generated output, missing release notes, or version mismatch. Interactive requests use isolated sandbox credentials and never expose production secrets.

An AI documentation assistant may explain and generate samples only from versioned published sources and must cite those sources.
